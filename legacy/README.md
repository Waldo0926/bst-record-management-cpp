# Legacy Coursework Source

`original_coursework.cpp` is the original single-file implementation written for a Data
Structures coursework project during my earlier undergraduate studies, converted from its original GBK/GB18030 text
encoding to UTF-8 so it is readable on GitHub.

The algorithmic logic is intentionally preserved here as historical source. It is **not**
the version intended to be compiled with a modern toolchain: it contains legacy APIs such
as `gets()` and manual `malloc/free` memory management.

The production-quality version of the same project lives in `src/` and `include/`.
